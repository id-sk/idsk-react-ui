# Tooltip

<Subtitle>Kontextová nápoveda s ikonou „i" — WCAG 2.1 kompatibilný komponent.</Subtitle>

## Overview (Prehľad)

Komponent `Tooltip` zobrazuje krátky pomocný text v plávajúcom kontajneri po nabehnutí myšou alebo kliknutí na ikonu „i". Ikona je vždy umiestnená vpravo od popisku. Kontajner sa automaticky prispôsobí dostupnému miestu vo viewporte.

## Správanie

| Akcia                     | Desktop                                     | Mobile                   |
| ------------------------- | ------------------------------------------- | ------------------------ |
| Nabehnúť myšou            | Otvorí po 200 ms (predchádza preblikávaniu) | —                        |
| Kliknúť / ťuknúť na ikonu | Prepne (toggle)                             | Prepne (toggle)          |
| Tab fokus                 | Fokus na ikonu, vizuálne zvýraznenie        | —                        |
| Enter / Medzerník         | Otvorí alebo zatvorí                        | —                        |
| Escape                    | Zatvorí otvorený tooltip                    | —                        |
| Ťuknutie mimo tooltipu    | —                                           | Zatvorí otvorený tooltip |

## Prístupnosť (Accessibility)

- Spúšťač je natívny `<button type="button">` — dostupný cez Tab
- Text „i" vo vnútri buttonu je obalený `<span aria-hidden="true">` — neprehováraný čítačkou
- Obsah tooltipu má `role="tooltip"` (nastavené automaticky cez Radix UI)
- Tlačidlo je prepojené s obsahom cez `aria-describedby`
- Na mobile je prítomný `aria-expanded` pre správne oznamovanie stavu
- Klávesa **Escape** vždy zatvorí otvorený tooltip
- Vizuálne zvýraznenie fokusu (`focus-visible`) je viditeľné a spĺňa kontrastný pomer WCAG 2.1 SC 1.4.3

## Obmedzenia obsahu

```tsx
// SPRÁVNE — čistý text
<Tooltip content="Zadajte dátum v tvare DD.MM.RRRR" ... />

// NESPRÁVNE — interaktívne prvky v toolipe porušujú WCAG 2.1 SC 1.4.13
// Prop content je typovaný ako string, TypeScript toto zachytí pri kompilácii
```

## Použitie

```tsx
import { Tooltip } from '@id-sk/react';

<Tooltip
  label="Dátum narodenia"
  content="Zadajte dátum v tvare DD.MM.RRRR."
  ariaLabel="Nápoveda k dátumu narodenia"
  preferredPosition="top"
/>;
```
