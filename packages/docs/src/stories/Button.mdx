# Button (Tlačidlo)

<Subtitle>
  Základný interaktívny prvok pre spúšťanie akcií s podporou variantov, farebných schém, ikon a
  prístupnosti.
</Subtitle>

## Overview (Prehľad)

Komponent `Button` slúži na spúšťanie akcií a navigáciu. Podporuje štyri vizuálne varianty (`primary`, `secondary`, `tertiary`, `tertiaryNoPadding`), farebné schémy (`primary`, `error`, `success`, `white`), tri veľkosti a ikony pred/za textom. Pomocou prop `asChild` môže byť vykreslený ako akýkoľvek iný element (napr. `<a>`).

## Prístupnosť (Accessibility)

- Tlačidlo je štandardný `<button>` element — dostupné cez klávesnicu (`Tab`, `Enter`, `Space`)
- `disabled` nastavuje `disabled` atribút, nie len vizuálny štýl
- Ikony majú `aria-hidden="true"` — sú dekoratívne a nečítajú ich čítačky obrazovky
- `asChild` s `<a>` vykreslí semantický odkaz s tlačidlovými štýlmi

## Použitie

```tsx
import { Button } from '@id-sk/react';

// Základné tlačidlo
<Button>Odoslať</Button>

// S variantom a farebnou schémou
<Button variant="secondary" colorScheme="error">Zmazať</Button>

// S ikonou
<Button leftIcon={<SendIcon />}>Odoslať správu</Button>

// Ako odkaz
<Button asChild>
  <a href="/dalsia-stranka">Pokračovať</a>
</Button>

// Zakázané
<Button disabled>Nedostupné</Button>
```
