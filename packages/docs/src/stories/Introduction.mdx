# IDSK UI Library

Vitajte v dokumentácii IDSK UI knižnice komponentov. Táto knižnica je postavená na Reacte, Tailwind CSS a Radix UI.

## Čo tu nájdete?

V ľavom menu nájdete zoznam dostupných komponentov. Každý komponent obsahuje:

- **Docs**: Kompletná dokumentácia, ukážky kódu a ovládacie prvky.
- **Stories**: Jednotlivé stavy komponentu pre rýchle testovanie.

## Inštalácia

```bash
npm install @id-sk/react
```

## Použitie

```tsx
import { Button } from '@id-sk/react';

export default function App() {
  return <Button>Klikni ma</Button>;
}
```
