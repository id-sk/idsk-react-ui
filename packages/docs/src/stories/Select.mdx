# Select (Rozbaľovacie pole)

<Subtitle>
  Rozbaľovací komponent pre výber jednej možnosti zo zoznamu s podporou skupín, tooltipov, validácie
  a ARIA atribútov.
</Subtitle>

## Overview (Prehľad)

Komponent `Select` nahrádza natívny `<select>` prvok vlastným dizajnom postaveným na Radix UI. Podporuje povinné aj nepovinné polia, pomocné popisy, chybové stavy, zoskupené možnosti a tooltip pri labeli. Automaticky generuje `id` pre správne prepojenie labelu s triggerom a nastavuje všetky potrebné ARIA atribúty.

## Štruktúra komponentu

```
Select
├── Label (Radix Label.Root)
│   ├── label text + required/optional badge
│   ├── labelDescription (podnadpis)
│   └── Tooltip (voliteľný)
├── Wrapper
│   └── RadixSelect.Root
│       ├── Trigger (tlačidlo)
│       │   ├── Value (zobrazená hodnota / placeholder)
│       │   ├── WarningIcon (iba pri variant="error")
│       │   └── ChevronIcon (rotuje pri otvorení)
│       └── Portal → Content → Viewport
│           ├── Item[] (jednotlivé možnosti)
│           └── Group[] + Label[] (ak sa použije prop groups)
├── inputDescription (hint, voliteľný)
└── errorDescription (iba pri variant="error")
```

## Prístupnosť (Accessibility)

- Trigger je `<button>` — plne ovládateľný klávesnicou (Space/Enter otvára, šípky navigujú, Escape zatvára).
- Label je prepojený s triggerom cez `htmlFor` / `id` (automaticky generované cez `useId` ak nie je zadané).
- `aria-describedby` odkazuje na `inputDescription` (hint) a/alebo `errorDescription` pokiaľ sú prítomné.
- `aria-invalid="true"` je nastavené pri `variant="error"`.
- `aria-required` je nastavené keď je `required={true}`.
- Hviezdička pre povinné pole má `aria-hidden="true"` — povinnosť je komunikovaná cez `aria-required`.
- Deaktivované položky majú `data-disabled` — Radix UI ich vylučuje z navigácie klávesnicou.

### Klávesové skratky

| Klávesa           | Akcia                           |
| ----------------- | ------------------------------- |
| `Space` / `Enter` | Otvorí/zavrie rozbaľovacie menu |
| `↑` / `↓`         | Navigácia medzi možnosťami      |
| `Home` / `End`    | Skok na prvú / poslednú možnosť |
| `Escape`          | Zatvorí menu bez zmeny hodnoty  |
| `Tab`             | Presunie fokus na ďalší prvok   |

## Varianty

| Variant   | Popis                                            |
| --------- | ------------------------------------------------ |
| `default` | Štandardný stav — tmavý border                   |
| `error`   | Chybový stav — červený border, ikona upozornenia |

## Veľkosti

| Size          | Výška                        | Typografia              |
| ------------- | ---------------------------- | ----------------------- |
| `default` (L) | 40 px mobile / 48 px desktop | `idsk-text-main-body`   |
| `sm` (M)      | 40 px fixne                  | `idsk-text-main-body-1` |

## Použitie

```tsx
import { Select } from '@id-sk/react';

// Základný príklad
<Select
  label="Krajina"
  placeholder="Vyberte krajinu"
  required
  options={[
    { value: 'sk', label: 'Slovensko' },
    { value: 'cz', label: 'Česká republika' },
    { value: 'at', label: 'Rakúsko' },
  ]}
/>

// Chybový stav
<Select
  label="Krajina"
  variant="error"
  required
  errorDescription="Vyberte platnú krajinu"
  options={[...]}
/>

// Zoskupené možnosti
<Select
  label="Mesto"
  placeholder="Vyberte mesto"
  required
  groups={[
    {
      label: 'Slovensko',
      options: [
        { value: 'ba', label: 'Bratislava' },
        { value: 'ke', label: 'Košice' },
      ],
    },
    {
      label: 'Česká republika',
      options: [
        { value: 'prg', label: 'Praha' },
      ],
    },
  ]}
/>

// Riadený (controlled) režim
const [value, setValue] = useState('');

<Select
  label="Krajina"
  value={value}
  onValueChange={setValue}
  options={[...]}
/>
```

## Vanilla HTML

Pre použitie bez Reactu / Radix UI použite natívny `<select>` s rovnakými CSS triedami.
JavaScript (`vanilla.ts`) sa stará iba o triedu `idsk-select--empty` (placeholder stav) — samotný `<select>` je plne funkčný aj bez JS.

### CSS triedy pre vanilla

| Trieda               | Kedy použiť                                                                          |
| -------------------- | ------------------------------------------------------------------------------------ |
| `idsk-select--empty` | Placeholder je viditeľný (žiadna hodnota nevybraná) — JS pridáva/odoberá automaticky |
| `idsk-select--error` | Chybový stav — červený border, ikona upozornenia                                     |
| `idsk-select--lg`    | Veľkosť L (default)                                                                  |
| `idsk-select--sm`    | Veľkosť M                                                                            |

> **Poznámka:** Rotácia chevróna pri otvorení dropdown menu nie je dostupná pre natívny `<select>` (prehliadač neexponuje open/close event). Všetky ostatné vizuálne stavy (hover, focus, disabled, error, empty) fungujú rovnako ako React verzia.
