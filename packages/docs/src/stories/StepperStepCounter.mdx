# StepperStepCounter (Počítadlo krokov)

<Subtitle>
  Textové počítadlo pozície v procese vo formáte „Krok N/N" — súčasť komponentu Stepper, použiteľné
  aj samostatne.
</Subtitle>

## Overview (Prehľad)

Komponent `StepperStepCounter` zobrazuje aktuálnu pozíciu vo viacstupienkovom procese v tvare „Krok N/N" (napr. „Krok 2/5"). Poskytuje stručnú textovú informáciu o postupe — dopĺňa vizuálny progres bar `StepperLoader`. Používa sa v hlavičke komponentu `Stepper`, ale možno ho nasadiť aj samostatne.

## Props komponentu

| Prop    | Typ      | Predvolená | Popis                   |
| ------- | -------- | ---------- | ----------------------- |
| `step`  | `number` | —          | Aktuálny krok (1-based) |
| `total` | `number` | —          | Celkový počet krokov    |

## Použitie

```tsx
import { StepperStepCounter } from '@id-sk/react';

// Krok 2 z 5
<StepperStepCounter step={2} total={5} />

// Posledný krok
<StepperStepCounter step={5} total={5} />
```
