# Textarea (Viacriadkové textové pole)

<Subtitle>

## Overview (Prehľad)

Komponent `Textarea` slúži na zadávanie dlhšieho textového vstupu používateľom. Podporuje dynamické počítadlo znakov, povinné aj nepovinné polia, pomocné popisy a chybové stavy. Automaticky generuje `id` pre správne prepojenie labelu s textovým poľom a nastavuje ARIA atribúty pre prístupnosť vrátane `aria-live` pre počítadlo.

## Prístupnosť (Accessibility)

- Label je prepojený s `textarea` cez `for` a `id`.
- Počítadlo znakov používa `aria-live="polite"`.
- Popis a chybová správa sú prepojené cez `aria-describedby`.
- Pri chybe je nastavený atribút `aria-invalid="true"`.
- Hviezdička pri povinnom poli má `aria-hidden="true"`.

## Použitie

```tsx
import { Textarea } from '@id-sk/react';

<Textarea
  label="Vaša správa"
  placeholder="Napíšte nám vašu spätnú väzbu..."
  maxLength={500}
  required
  description="Maximálne 500 znakov"
/>;
```
